# Homelab Roadmap

This roadmap tracks areas I want to improve, document, or learn more about over time. It is a learning plan, not a promise that every item will be implemented.

## Documentation

- Keep the VM/LXC inventory current
- Add sanitized configuration examples when they are useful
- Record important troubleshooting lessons
- Expand diagrams as the environment changes
- Keep service documentation consistent with the live lab

## Proxmox & Virtualization

- Continue improving VM and LXC resource allocation
- Learn more about backups and recovery
- Improve understanding of device passthrough
- Keep experimenting with Linux virtual machines
- Learn more about service isolation and recovery

## Networking

- Continue learning routing, DNS, and firewall concepts
- Improve OPNsense knowledge
- Improve network troubleshooting workflows
- Learn more about network segmentation and isolation
- Document useful networking lessons without exposing the live topology

## Storage

- Improve ZFS knowledge
- Improve storage organization and capacity planning
- Learn more about backup strategies
- Improve understanding of recovery procedures
- Continue refining SMB and shared-storage management

## Monitoring & Reliability

- Expand useful monitoring in Uptime Kuma
- Improve awareness of service dependencies
- Document common failure and recovery scenarios
- Improve reliability of important self-hosted services

## Home Automation

- Continue experimenting with ESPHome and ESP32 hardware
- Improve Home Assistant organization and troubleshooting skills
- Document useful automation patterns without publishing secrets

## Security

- Keep public configuration examples sanitized
- Avoid exposing credentials, keys, tokens, and private endpoints
- Continue improving firewall and network-isolation knowledge
- Review public documentation periodically for accidental sensitive information

## Long-Term Goal

Use the homelab as a continuously evolving practical environment for building real IT, Linux, networking, virtualization, storage, automation, and troubleshooting experience.
