# Storage

Storage in my homelab is built around local disks managed through Proxmox and ZFS.

## Current Storage

- SSD storage for the host and faster workloads
- 4 TB HDD storage for larger data
- ZFS for storage management
- SMB for network file sharing

## What I Am Learning

- ZFS datasets
- Storage allocation for VMs and containers
- Network shares
- Permissions
- Capacity planning
- Backup and recovery concepts

## Documentation Policy

This public repository focuses on architecture and lessons learned rather than exposing sensitive paths, credentials, or private share configuration.
