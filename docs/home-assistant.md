# Home Assistant & ESPHome

Home automation in the homelab is centered around **Home Assistant OS**, running as Proxmox VM **100 (`haos18-2`)**.

## Home Assistant OS

Home Assistant provides the central platform for managing and experimenting with home automation.

Running it as its own VM gives the workload a complete appliance-style environment and keeps it separate from unrelated services.

## ESPHome

I use **ESPHome** with ESP32 devices for custom automation and electronics experiments.

This gives me hands-on experience with:

- ESP32 devices
- Sensors and outputs
- Device configuration
- Home Assistant integrations
- Network-connected embedded devices
- Troubleshooting hardware and software together

## What I Am Learning

- Home-automation architecture
- Device integrations
- ESPHome configuration
- ESP32 hardware
- Automation troubleshooting
- Service isolation through virtualization

## Privacy

Public documentation does not include Home Assistant access tokens, ESPHome encryption keys, Wi-Fi credentials, private device identifiers, or other secrets.
