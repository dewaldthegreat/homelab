# Linux Lab

Proxmox VM **106 (`test`)** is a Linux virtual machine used specifically for testing and experimentation.

## Why I Keep a Test VM

A dedicated test VM gives me a place to try changes without risking more important homelab services.

I use it for areas such as:

- Linux administration
- Package and software testing
- Service configuration
- Permissions
- Networking
- Troubleshooting
- Learning command-line tools
- Testing changes before applying similar ideas elsewhere

## Learning Approach

The purpose of this VM is not to provide a permanent production service. It is intentionally an experimentation environment where I can build, change, break, recover, and learn.

## Isolation

Keeping experiments in their own VM makes it easier to understand what changed and reduces the chance that testing affects persistent services in the rest of the lab.

## Public Documentation

Commands or configurations added to this repository will be sanitized before publication and will not include passwords, tokens, keys, or sensitive network details.
