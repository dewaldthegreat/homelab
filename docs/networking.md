# Networking

Networking is one of the main areas I use my homelab to learn and experiment with.

## Technologies

### OPNsense

Used for firewall, routing, and network configuration experiments in the lab.

### Pi-hole

Used for network-wide DNS filtering.

### SMB

Used for file sharing between systems on the local network.

### Sunshine + Moonlight

Used for low-latency desktop and game streaming across the local network.

## What I Practice

- IP addressing and subnetting
- Routing
- DNS
- Firewall rules
- Network troubleshooting
- Service connectivity
- Virtual networking in Proxmox
