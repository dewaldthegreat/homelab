# Proxmox VE

Proxmox VE is the main virtualization platform in my homelab.

## Host Hardware

| Component | Specification |
|---|---|
| CPU | Intel Core i7-10700 |
| Cores / Threads | 8 Cores / 16 Threads |
| Memory | 32 GB DDR4 |
| Storage | SSD + 4 TB HDD storage |
| Networking | Dual Gigabit Ethernet |

## What I Use It For

- Running virtual machines
- Running Linux containers
- Testing Linux desktop and server environments
- Hosting network services
- Experimenting with storage and networking
- Learning troubleshooting and virtualization concepts

## Areas I Am Learning

- VM and container resource allocation
- Device passthrough
- Storage management
- ZFS
- Networking and virtual bridges
- Backups and recovery
- Service isolation
