# Remote Desktop & Streaming

The homelab is also used for Linux desktop experimentation and low-latency remote desktop/game streaming.

## Omarchy — VM 107

**Omarchy** runs as Proxmox VM **107 (`Omarchy`)** and provides a Linux desktop environment inside the lab.

Using a desktop Linux VM gives me a safe place to experiment with:

- Linux desktop configuration
- Virtualized graphics and display settings
- Application testing
- Remote access
- Troubleshooting a full desktop workload

## Sunshine + Moonlight

I use **Sunshine** and **Moonlight** for low-latency desktop and game streaming across the local network.

This gives me practical experience with:

- Host/client streaming
- LAN performance
- Display and refresh-rate configuration
- Graphics troubleshooting
- Network latency and connectivity

## Privacy

This public page does not contain private host addresses, pairing information, access credentials, or externally reachable streaming endpoints.
